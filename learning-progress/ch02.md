# Chapter 2: LLM API basics

- Provider-agnostic LLM calls through LiteLLM's unified API (running on Gemini)
- LLM APIs are stateless, so multi-turn chat means managing and resending the message history yourself
- Structured output: constraining model responses to a Pydantic schema via `response_format`
- Concurrent LLM calls with `asyncio.gather`, throttled by per-provider `asyncio.Semaphore` limits, with `num_retries` for backoff
- Built a GAIA eval harness: structured-output solver, exact-match scoring, results grouped per model
- Diagnosed a silent eval failure: a broad `except` hid a `NameError`, giving 0% accuracy across all models; fixed by failing fast on config errors before any API call
- Structured the harness as a package (`schema`, `solver`, `scoring`, `runner`) with concurrency limits in `config.yaml` and the provider resolved through LiteLLM
